# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-02

### Added
- Initial unified release combining Python SSE and Node.js Stdio implementations
- 11 comprehensive tools for network analysis
- Threat detection integration with URLhaus blacklist
- Credential extraction from PCAP files (HTTP Basic Auth, FTP, Telnet, Kerberos)
- SSE (Server-Sent Events) MCP transport layer
- Web-based status dashboard
- Session management with automatic cleanup
- Comprehensive logging with color support
- Full documentation and README

### Features
- `list_interfaces` - List network interfaces
- `capture_live` - Real-time packet capture
- `analyze_pcap` - PCAP file analysis
- `get_protocols` - Protocol list retrieval
- `get_packet_statistics` - Packet statistics
- `extract_fields` - Field extraction and statistics
- `analyze_protocols` - Protocol-specific analysis
- `analyze_errors` - Error analysis
- `check_threats` - Threat detection from live traffic
- `check_ip_threats` - IP threat intelligence check
- `extract_credentials` - Credential extraction from PCAP files
